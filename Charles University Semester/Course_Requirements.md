    - watch videos, save them for later
    - attend all lectures, ask questions
1. Exam (written exam, 6-8 questions (150 minutes), optional oral part)

2. Homework
    - minimum 90 points, goal: 130+ points, to get extra points for exam
    - every week on ReCodEx
3. Final project @ **GitLab**
    - finish a project, milestones:
        1. specifications - end of october
        2. 30kB-s of source code - middle of november
        3. 45kB-s of source code - end of november
        4. 60kB-s of source code - before winter break
        5. finished project - before winter break
    - do presentations for each stage
4. Practical exam
    - 3 attempts, in january
